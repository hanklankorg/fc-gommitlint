# Security

## Reporting a vulnerability

Please report vulnerabilities privately to <janderssonse@proton.me>. Include
the project URL, affected version, a description, reproduction steps, and links
to any public discussion. Please do not open a public issue before disclosure
has been coordinated.

## Supported versions

| Version               | Supported |
| --------------------- | --------- |
| Latest tagged release | Yes       |
| Older releases        | No        |

Before 1.0, only the latest tagged release receives security fixes.
Upgrade to the latest release before reporting or validating a fix.
