= Gommitlint Documentation
:description: Git commit message linter with conventional commits, sign-off, and signature policy
:relfilesuffix: .adoc

Gommitlint validates git commit messages against configurable rules for
Conventional Commits, DCO sign-off, spelling, author email, and signature
presence, format, type, and key inventory.

This site is for people using Gommitlint.
Start with xref:install.adoc[Install], then follow the xref:tutorial.adoc[Tutorial].
Source, issues, and the documents for people working on Gommitlint itself are in the {repo-base}[itiquette/gommitlint] repository.
